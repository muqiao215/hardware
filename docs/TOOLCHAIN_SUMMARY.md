## 6. 快速命令速查

### Arduino
```powershell
# 编译 + 烧录
arduino-cli compile -b arduino:avr:nano -p COM4 -u E:\web\embedded\arduino_robot_arm
# 串口
arduino-cli monitor -p COM4 -c baudrate=115200
```

### 51 单片机 (STC)
```powershell
# 编译
sdcc main.c && packihx main.ihx > main.hex
# 烧录 (运行后断电重新上电)
stcgal -p COM4 main.hex
```

### STM32 (UART 模式)
```powershell
# BOOT0=1, 复位进入 Bootloader
stm32loader -p COM4 -e -w -v firmware.bin
```

### STM32 (ST-Link)
```powershell
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg -c "program firmware.elf verify reset exit"
```

### CMake + Ninja 构建
```powershell
cmake -B build -G Ninja
ninja -C build
```
